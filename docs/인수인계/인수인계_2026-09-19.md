## 5. 테스트 방법 — 구매 → 청약 전 구간

```bash
cd web && npm run dev

J=/tmp/jar.txt; rm -f $J

# 1) 구매 전 — canBid=false 여야 한다
curl -s -b $J -c $J localhost:3000/api/ipo | python3 -c "import sys,json;print(json.load(sys.stdin)['canBid'])"

# 2) 청약 시도 — 거부돼야 한다
curl -s -b $J -c $J -X POST localhost:3000/api/ipo \
  -H 'Content-Type: application/json' -d '{"candidate":"a"}'

# 3) 빵 구매 — depth는 오늘 폭(페이지의 rate)과 정확히 같아야 한다
curl -s -b $J -c $J -X POST localhost:3000/api/fill \
  -H 'Content-Type: application/json' -d '{"productNo":31,"depth":0.3}'

# 4) 다시 청약 — 이제 된다
curl -s -b $J -c $J -X POST localhost:3000/api/ipo \
  -H 'Content-Type: application/json' -d '{"candidate":"a"}'
```

`depth`가 틀리면 `"오늘 폭이 아닙니다."`가 온다. 오늘 폭은 `/`의 SSR 데이터나
`/api/cron/publish`(dryRun)에서 확인한다.

**크론 dryRun 확인:**
```bash
SEC=$(grep '^CRON_SECRET=' web/.env.local | cut -d= -f2)
curl -s -H "Authorization: Bearer $SEC" localhost:3000/api/cron/publish | python3 -m json.tool
```

**재고 확인:** `curl -s localhost:3000/api/stock | python3 -m json.tool`
→ `source`가 `cafe24` / `shop` / `code` 중 무엇인지 보면 어느 단계가 쓰였는지 안다.

## 6. 밟으면 안 되는 지뢰 (전부 주석에 적어뒀지만 요약)

| 함정 | 어디 | 요점 |
|---|---|---|
| **부동소수점 10원** | `floorTo10` 4곳 | `21000 * (1 - 0.3)` = `14699.999...`. `Math.round`를 먼저 거치게 고쳤다. 새 계산 자리를 만들면 같은 규칙을 쓸 것 |
| **크론 UTC 환산** | `api/cron/restore` | `15:10 UTC 월 = 00:10 KST 화`. 그 순간의 KST 날짜는 되돌릴 그날이 아니다. 두 시간 뒤로 민다 |
| **폭 불일치** | `rateFor()` | 화면·차트·서버 검증이 **전부 이 함수 하나**를 써야 한다. 한쪽만 보정을 넣으면 예약이 전부 튕긴다 |
| **품절 오독** | `lib/stock.ts` | 상세 페이지의 `aSoldoutDisplay = {"33":"품절"}`은 **상태가 아니라 문구**다. 이걸 상태로 읽어 생지를 열흘간 품절로 뒀었다 |
| **저장소 없음 ≠ 품절** | `lib/fills.ts` | 예전엔 DB가 없으면 `filled:false`를 반환해 화면이 "다 나갔습니다"로 거짓말했다. 지금은 메모리 폴백 |
| **원가 기록** | `lib/priceSync.ts` | 카페24는 이전 가격을 보관하지 않는다. `daily_plans`에 적어둔 것이 **유일한 복원 근거**다 |

## 9. graft (2026-09-19 설치됨)

이 저장소는 `graft/`로 인덱싱돼 있다. 74개 카드, 소스 71개를 커버한다.

```bash
graft grep "<심볼>"        # 모든 출현 — 한국어 주석도 찾는다
graft callers <심볼>       # 누가 부르는가
graft skeleton <파일>      # 파일 API 한눈에
graft ask "<질문>"         # ⚠️ 영어로 물어야 한다
```

**한국어 `ask`는 0건이 나온다** — 인덱스 prose가 영어다. 개념 질문은 영어로,
심볼·한국어 주석 찾기는 `grep`으로.

코드를 고치면 `graft build`로 재색인할 것(자동 재색인 훅은 확인하지 못했다).
