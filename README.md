# 막지 빵장 (MAKJI Bread Market)

㈜스윗앤스위츠 웰니스 베이커리 **MAKJI(막지)** 기업연계 프로젝트입니다.
코스피가 그날의 빵값을 정하는 자사몰 커머스로, 실제로 동작하는 MVP입니다.

> **국장이 끝나면, 빵장이 시작된다.**
> 오르면 든든한 한 끼(식사빵), 내리면 달달한 위로(디저트). 株式 & 主食.

## 서비스가 하는 일

**왜** — 자사몰 월 로그인 90회, 월 주문 147건. 주문은 나오는데 **다시 올 이유**가 없습니다.
**어떻게** — 거래일마다 바뀌는 코스피가 그날의 할인을 정합니다. 가격이 매일 다르니 확인하러 옵니다.
**누가** — 막지 자사몰 방문자. 로그인 없이 브라우저 표식만으로 동작합니다(배당을 받을 때만 자사몰 아이디를 한 번 연결).

### 평일(거래일) 하루

| 시각 (KST) | 화면 | 자사몰 가격 |
|---|---|---|
| 09:00 – 15:30 | 코스피 실시간 차트, 빵마다 **"15:30 예상가"** | **정가** — 화면도 정가를 크게 보여줍니다 |
| **15:30** | 종가로 오늘 할인 확정, **빵장 개장** | 오늘 할인 빵의 판매가를 **할인가로 자동 변경** |
| 15:30 – 24:00 | 할인가 확인 · 빵장 예약 · 관심빵 담기 | 할인가 — 자사몰에서 평소처럼 결제 |
| 00:10 | 빵장 마감 | 기록해 둔 **원래 가격으로 복원** |

### 주말 · 공휴일 (휴장)

코스피가 쉬면 빵장도 쉽니다(거래소 휴장일 달력 2026·2027 반영). 화면이 **DIVIDEND DAY**로 바뀌어 이번 주 활동을 결산하고, 모아 둔 **배당금 쿠폰**으로 정가 빵을 살 수 있습니다.

### 네 가지 기능

- **오늘의 빵시장** — 코스피가 **움직인 폭**이 할인율을, **방향**이 대상 라인을 정합니다. 상승 = 식사빵, 하락 = 디저트, 0.1% 미만 보합 = 전 상품. 라인 빵이 3종보다 적으면 라인 밖에서 채웁니다.
- **내 빵 포트폴리오** — 관심빵을 옵션별로 담고 개수를 정합니다. 오늘 할인·품절 상태, 취향 비중 도넛, 할인 중인 관심빵 한 번에 예약, 관심빵이 할인되면 웹 푸시 알림.
- **주말 배당** — 한 주 활동 3가지를 1점씩 셉니다.

  | 활동 | 세는 기준 |
  |---|---|
  | 관심빵 담기 | 그 주에 하트를 눌렀다 |
  | 빵장에서 구매 | 연결한 자사몰 아이디로 **거래일 15:30~24:00에 한 주문**(취소 제외) |
  | 거래일 출석 | 그 주 거래일 3일 이상 방문(휴장일이 낀 주는 거래일 − 1일) |

  1점 300P · 2점 500P · 3점 800P를 **토요일 00:05에 자동 결산**해 배당금 통장에 넣습니다.
  휴장일 00:05에 잔액이 **100P 단위 할인 쿠폰**으로 자사몰 쿠폰함에 들어가고, **1만 원 이상 주문에서 결제금액의 15%까지** 씁니다. 쿠폰은 **주말·공휴일에만** 쓰고, 안 쓰면 잔액으로 돌아옵니다. 그 달에 안 쓴 배당은 월말에 소멸합니다.
- **절기빵 공모** — 다음에 나올 빵을 청약으로 고릅니다. 관리자 화면에서 켜야 보입니다(기본 꺼짐).

## 할인율은 이렇게 정해집니다

```
오늘 이 빵의 할인율 = MIN( 구간 기본 + 하락장 보정 + 수요 보정 + 재고 보정 ,  38% )

  구간 기본   5 ~ 30%    코스피가 움직인 폭(아래 표)
  하락장      +3%p       내려서 마감한 날(0.1% 미만 보합은 제외)
  수요 보정   +2~3%p     관심은 많은데 예약이 적은 빵
  재고 보정   +1~2%p     재고가 많이 남은 빵
  상한        38%        기업 확인값. 어떤 설정으로도 넘지 않습니다
```

구간 경계는 코스피 **5년 1,218거래일 실측 분포**로 잡았습니다([검증 문서](./docs/설계/할인율_구간_실측검증.md)).

| 코스피 등락폭 | 기본 할인 | 실측 빈도 | 1년에 |
|---|---:|---:|---:|
| 0 ~ 0.3% | 5% | 22.2% | 54일 |
| 0.3 ~ 0.8% | 10% | 28.1% | 69일 |
| 0.8 ~ 1.5% | 15% | 26.4% | 65일 |
| 1.5 ~ 2.5% | 20% | 14.1% | 35일 |
| 2.5% 이상 | 30% | 9.2% | 23일 |

기본 할인 기대값은 **13.5%**입니다. 구간 표는 관리자 화면에서 바꿀 수 있습니다.

> 코스피는 **원가 지표가 아니라 응원 지표**입니다. 빵 원재료 가격과의 경제적 인과를 주장하지 않습니다.

## 지금 상태 (2026-09-29)

| 기능 | 상태 |
|---|---|
| 빵장 개장·마감·휴장 달력, 5구간 할인, 상승/하락 라인 | ✅ 동작 |
| 15:30 자사몰 판매가 자동 할인 · 00:10 복원 | ✅ 동작 — 체험몰(makjitest)에서 매 거래일 실행 중 |
| 수요·재고 보정 | ✅ 동작 — 관심·예약이 쌓인 빵에 붙습니다 |
| 15:30 전 정가 표시와 "15:30 예상가" | ✅ 동작 |
| 관심빵 포트폴리오 · 옵션별 예약 · 할인 알림 | ✅ 동작 — 알림은 손님이 브라우저에서 허용해야 받습니다 |
| 주말 배당 — 점수 · 토요일 자동 결산 · 쿠폰 발급·회수 | ✅ 동작 — 9/29 체험몰에서 지급 → 쿠폰 → 주문서 적용까지 확인 |
| 주말 배당 — 구매 점수(자사몰 주문 조회) | ✅ 동작 — 실제 주문으로의 확인은 체험몰에 무통장 계좌를 등록한 뒤 |
| 절기빵 공모 | ✅ 동작 — 기본 꺼짐 |

**알아 두실 한계**

- **한정 수량은 빵장 예약에만 걸립니다.** 할인은 자사몰 판매가를 바꾸는 방식이라, 15:30~24:00에 자사몰에서 사는 손님은 누구나 할인가입니다. "예약한 사람만 할인"을 하려면 예약마다 쿠폰을 주는 방식으로 바꿔야 합니다.
- **자사몰 장바구니에 대신 담지 못합니다.** 빵장은 로그인이 없어 손님의 자사몰 장바구니를 모릅니다. "자사몰에서 결제 이어가기"는 상품 페이지를 엽니다.
- **기업용 리포트 화면은 없습니다.** 관심·예약·방문·배당 데이터는 DB에 쌓이고, 관리자 화면에서는 오늘 가격·구간·수량·배당을 다룹니다.

**기업과 정할 것**

1. **실제 막지몰로 옮기기** — 환경변수 `CAFE24_MALL_ID` · `NEXT_PUBLIC_SHOP_BASE` 등을 실제 몰 값으로 바꾸고 카페24를 다시 연결합니다([세팅 가이드](./docs/빵장_세팅_가이드.md)).
2. **15:30 판매가 변경 승인** — "15:30~24:00 동안 자사몰 판매가를 API로 바꾸고 자정에 되돌려도 됩니까?"
3. **상품별 마진 상한** — 받으면 38% 상한보다 먼저 적용합니다(자리는 코드에 있음).
4. **주간 배당 예산 · 할인 수량** — 관리자 화면에서 바꿉니다(배당 예산 기본 50만P).

## 개발자용

### 시작하기

```bash
cd web
npm install
cp .env.example .env.local   # 값은 세팅 가이드의 환경변수 표대로
npm run dev                  # http://localhost:3000
```

- 환경변수 전체 목록과 뜻은 [세팅 가이드의 환경변수 표](./docs/빵장_세팅_가이드.md#환경변수-표--vercel에-넣을-열쇠)에 있습니다. `.env.local`은 커밋하지 않습니다.
- DB는 [`web/supabase/지금_실행할_SQL.sql`](./web/supabase/지금_실행할_SQL.sql) 한 장을 Supabase SQL Editor에 붙여넣고 Run하면 됩니다(여러 번 돌려도 안전, 맨 아래 확인표).
- `npm run build` · `npm run lint` · 검증 스크립트는 `web/`에서 `npx tsx scripts/verify-holidays.ts`처럼 하나씩 실행합니다

### 자동 실행 (Vercel Cron, Pro 요금제)

| 경로 | 스케줄 (UTC) | KST | 하는 일 |
|---|---|---|---|
| `/api/cron/publish` | `30 6 * * 1-5` | 평일 15:30 | 오늘 할인을 자사몰 판매가에 반영, 관심빵 알림. 휴장일·코스피 수집 실패 시 아무것도 안 함 |
| `/api/cron/restore` | `10 15 * * 1-5` | 화~토 00:10 | 기록해 둔 원가로 복원(기록 없으면 안 함) |
| `/api/cron/dividend` | `5 15 * * *` | 매일 00:05 | 토요일이면 주간 배당 결산 → 휴장일이면 쿠폰 발급, 거래일이면 안 쓴 쿠폰 회수 |

### 주의

- **API 키는 커밋하지 않습니다.** `.env.local`로 관리하고 `.gitignore`에 들어 있습니다.
- **상품 콘텐츠 AI 자동 생성·업로드 금지.** 이미지·상품 콘텐츠는 브랜드 자산이라 기업 승인을 거칩니다.
- 카페24 연동 테스트는 실제 자사몰이 아니라 **체험몰**에서 합니다.
- 방문자 구분은 서버가 발급한 난수입니다. 누구인지는 모르고 **같은 브라우저인지만** 압니다.
