# korea_traditional

㈜스윗앤스위츠 웰니스 베이커리 브랜드 **MAKJI(막지)** 기업연계 프로젝트.
AI 기반 Food FinCommerce Platform — Bread Market MVP.

## 프로젝트 개요

시장 데이터를 식품 소비 경험에 접목해, MAKJI 자사몰(카페24)에 반영 가능한
구매 전환 기능을 기획·구현한다.

- 기간: 2026.09.07 ~ 09.30 (4주)
- 진행 보드: https://github.com/users/2ma1995/projects/2

## 구현 흐름

```
1. 데이터 수집   팀 서버가 매일 외부 API에서 시장 데이터를 가져온다
2. 로직 판단     그 데이터로 '오늘 뭘 할인할지' 서버가 자체 계산한다
3. 자사몰 반영   카페24 API로 실제 상품가·쿠폰을 업데이트한다
```

## 기술 스택

- Next.js + TypeScript (Vercel 배포)
- 카페24 Admin API — REST / JSON / OAuth 2.0, HTTPS 전용
- 외부 데이터: KAMIS 농산물유통정보, 기상청 단기예보, 한국수출입은행 환율,
  금융위원회 지수·일반상품시세, 네이버 데이터랩

자사몰(makji.kr)은 카페24 몰이며 프론트가 jQuery 1.11.2 환경이다.
스킨을 직접 수정하지 않고 **별도 도메인에 우리 앱을 배포**한 뒤 API로 연동한다.

## 주의

- **API 키는 커밋하지 않는다.** `.env.local`로 관리하고 `.gitignore`에 포함되어 있다.
- **상품 콘텐츠 AI 자동 생성·업로드 금지.** 이미지·상품 콘텐츠는 브랜드 자산이므로
  기업 사전 협의·승인을 거쳐 적용한다 (승인 큐 구조로 설계).
- 카페24 연동 테스트는 실제 자사몰이 아니라 **팀별 무료체험몰**에서 한다.
