# 통합 기획안 — 바뀐 것만

2026-09-15 · 원본: `MAKJI_Bread_Market_호가창_도사_통합기획안.docx`
통합본: `MAKJI_Bread_Market_통합기획안.md`

호가창 기획안의 **구조는 그대로 갑니다.** 절대등락률·재고 분리·도사 배치 모두 유지했습니다.
아래 6개만 바꿨고, 이유를 같이 적었습니다.

---

## 1. MVP를 기능 하나로 줄였습니다

멘토: *"MVP는 진짜 작은 기능 **하나**"*

기획안 12장의 MVP 범위에 기능이 넷이었습니다 — 호가창 · 재고 배정 · 체결 · 도사.

**→ 호가창 하나만 남기고 나머지는 Phase 2 + 어펜딕스로 내렸습니다.**

고른 기준은 명확합니다. RFP 필수 요건("시장데이터를 가격 변경 기준으로")을 만족하는 건 호가창뿐입니다.
도사는 그걸 단독으로 충족하지 못한다고 기획안 1-3에도 적혀 있습니다.

버리는 게 아니라 **어펜딕스로 내리는 것**입니다. 멘토의 "본편 5장, 별첨 100장" 전략입니다.

## 2. 빵장을 야간에 엽니다 — 20:00 ~ 24:00

기획안에 체결 시점이 비어 있었습니다. **주식장이 끝난 뒤 저녁**으로 정했습니다.

| 이유 | 근거 |
| --- | --- |
| 오늘 등락률이 **확정된 뒤**다 | 장중에 열면 범위가 계속 변해 설명할 수 없다 |
| 사람들이 실제로 사는 시간 | 오후 8시부터 주문 증가, **밤 11시 정점**, 20~23시가 하루의 **약 33%** |
| 감정이 정리되는 시간 | 손익 확인 직후 |
| 주식시장에도 있는 구조 | 정규장 뒤 **시간외 거래**와 같은 자리 — 억지 비유가 아니다 |
| 희소성 | 4시간만 열림, 매일 같은 시각 → 습관 |
| 만들기 쉽다 | 장중 실시간 추적 불필요. 마감 데이터 하루 한 번 |

**주말·휴장일은 빵장도 쉽니다.** "주식시장이 쉬는 날은 빵장도 쉽니다"가 규칙으로 더 선명하고,
매일 열면 평일 습관이 약해집니다.

> **캐치프레이즈: "장이 끝나면, 빵장이 열립니다."**

## 3. 맨 위에 즉시구매 칸을 넣었습니다

기업 피드백이 **"구매 허들이 높다"** 였는데, 호가창은 그대로 두면 허들을 **더** 올립니다 —
주문 걸고, 기다리고, 떨어질 수도 있습니다.

```
3,610원   지금 바로 구매      수량 제한 없음   ← 새로 넣은 칸
3,420원   한정 12개
3,230원   한정 4개
```

- **아무도 빈손으로 나가지 않습니다**
- 주식을 모르는 기존 고객은 이 칸만 써도 됩니다
- 아래로 갈수록 싸지는 재미는 그대로입니다

주식의 시장가 주문과 같은 개념이라 설명도 짧습니다. **이 칸이 없으면 안 됩니다.**

## 4. 미체결 보상을 크레딧 → 우선권으로 바꿨습니다

멘토가 크레딧 선순환을 두 번 말했는데 기획안에 빠져 있었습니다. 그래서 넣으려다
**구멍을 발견했습니다** — 주문에 선결제가 없으니, 최저가만 계속 걸어 크레딧만 모으는 사용이 가능합니다.

**→ 1순위는 우선권입니다.**

```
3,040원 주문은 체결되지 않았습니다.
3,230원 물량이 2개 남았습니다. → 지금 바로 체결하기
도전에 대한 보상으로 내일 같은 가격의 우선권을 드립니다.
```

- **비용 0**, 재방문 동기 있음, **어뷰징해도 이득 없음** (우선권은 진짜 살 사람에게만 가치 있음)
- 크레딧은 "연속 3회 미체결"처럼 달래야 하는 순간에만. 유효기간·최소주문금액 조건

**어뷰징 방지도 표로 정리했습니다** — 1인 1일 주문 2~3건, 동일 호가 1인 1건,
체결 후 제한시간 미결제 시 다음 순번 이동.

## 5. 구간을 0.3 / 0.8 / 1.5%로 바꿨습니다 — 실측 근거

KOSPI 3년 실측으로 검증했습니다 (Yahoo `^KS11`, 2023-09 ~ 2026-09, **727 거래일** 직접 집계).

| 구간 | 일수 | 비율 | 연 환산 | 최저호가 |
| --- | --- | --- | --- | --- |
| 0.3% 미만 | 158일 | 21.7% | 54일 | −5% |
| 0.3 ~ 0.8% | 177일 | 24.3% | 60일 | −10% |
| 0.8 ~ 1.5% | 184일 | 25.3% | 63일 | −15% |
| 1.5% 이상 | 208일 | 28.6% | 71일 | −20% |

**네 구간이 거의 균등하게 갈립니다.** 어느 구간도 희귀하지 않아 "1년에 며칠만 열리는 가격"이 없습니다.

기획안의 구간(0.3/0.8/1.5/2.0)과 거의 같지만, **최상단을 2.0% → 1.5%로 낮췄습니다.**
그리고 이전 기획의 구간(1/1.5/3/4.5%)이 왜 안 되는지도 숫자로 나왔습니다.

```
1.0% 이상  44.2%   ← 절반 가까운 날이 최하단에 몰림
4.5% 이상   6.1%   ← 최대 할인이 연 15일뿐
```

## 6. 도사는 증권사 연동보다 "빵 매수 이력"이 먼저입니다

기획안의 도사는 **HTS 거래내역 CSV 업로드**를 요구합니다. 가장 약한 고리입니다 —
금융 민감정보, 파일 내려받기, 개인정보 동의, 그리고 **주식 안 하는 사람은 아예 못 씁니다.**

그런데 **호가창을 만들면 우리가 이미 투자 행동 데이터를 갖습니다.**

| 우리가 갖는 것 | 읽어낼 수 있는 것 |
| --- | --- |
| 언제 주문했나 | 개장 직후 급한가, 마감 직전까지 재는가 |
| 얼마에 걸었나 | 안전한 상단인가, 최저가 도전인가 |
| 체결/미체결 | 욕심의 결과 |

```
당신의 빵 투자 성향 — 「저점 사냥꾼」
최저호가 5회 도전, 체결 1회.
```

업로드 불필요, 첫 주문부터 동작, 개인정보 리스크 없음.
**증권사 연동을 버리는 게 아니라 순서를 뒤집는 것**입니다.

## 타깃 문장에 한 줄 추가했습니다

보내주신 포지셔닝 문장에서 **"이 타깃이 빵을 살 이유"** 가 비어 있었습니다.
멘토가 물은 질문이 정확히 그것이었습니다 — *"주식을 모를 때마다, 평소에 안 먹던 막지 빵을 사게 될까?"*

익숙한 것과 사고 싶은 것은 다릅니다. 세 가지로 채웠습니다.

1. **시간이 이미 있다** — 장 마감 후 저녁, 온라인 구매가 몰리는 시간
2. **실패해도 3,000원이다** — 저점 매수의 재미는 같고 손실은 없다
3. **감정이 남는다** — 번 날은 자축, 잃은 날은 위로

그리고 **"일간 움직임" → "일간 절대등락률"** 로 다시 못 박았습니다.
방향인지 크기인지 흐려지면 "오르면 할인, 내려도 할인"이라는 지적을 받습니다.

## 구현 상태

절기·대회를 걷어냈지만 **아래는 그대로 살아 있습니다.**

- KOSPI 실시간 수집 (네이버 + Yahoo 폴백)
- 등락률 → 구간 → 호가 계산
- 구간 설정 화면 (관리자가 "몇 %면 몇 %까지" 직접 수정)
- **카페24 판매가 실제 변경** — 체험몰에서 검증 완료 (5,000원 → 3,500원)
- 관리자 로그인 · 상품 선택 · 상한 38% 강제
- Supabase 저장소

**새로 만든 것** (9/16)

- **증권 앱 한 화면** — 관심상품 → 종목 → 호가 | 체결 | 정보 → 하단 [사기]. 랜딩 페이지 형태는 폐기
- **오늘 내 종목 (2층)** — 09:00 전에 종목 하나를 고르고 잠깁니다. 그 종목의 오늘 등락이 내 자리를 정합니다.
  장중엔 내 빵값이 실시간으로 움직이고(5초), 15:30에 확정됩니다
- **내 자리보다 깊은 칸은 닫히고 위 칸은 전부 열립니다** — 싼데 적은 내 자리 vs 덜 싼데 많은 위 칸, 그게 선택입니다
- **체결 (A안, 선착순 즉시)** — 걸면 그 자리에서 되거나 안 됩니다. 밤엔 잔량 막대가 실시간으로 줄어듭니다
- **체결 탭** = 오늘 사람들이 어느 칸에 앉았나 (시황). 10명 미만이면 비율 대신 인원만

**뺀 것**: 수익률 직접 입력 · 스크린샷 업로드 — 결과를 보고 입력하는 건 검증이 안 됩니다

**아직 없는 것**: 가격별 수량 관리자 입력, 우선권 발급, 쿠폰 발급(기업 확인 후), 시세 수집 실패 시 샘플 표기.
