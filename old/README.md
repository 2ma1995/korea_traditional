# old — 지금 서비스와 맞지 않는 이전 자료

2026-09-24에 옮겼다. 지우지 않고 원래 폴더 구조 그대로 둔다(`old/docs/기획/…` = 예전 `docs/기획/…`).
배포(`web/`)와 발표(`deck/`)에는 쓰이지 않는다. 지금 동작은 `docs/설계/팀공유_빵장_설계도.md`가 기준이다.

| 폴더 | 무엇 | 왜 옮겼나 |
|---|---|---|
| `web/src` | 절기 화면(`/season`)·절기 기록장(`/archive`)과 그 두 페이지만 쓰던 컴포넌트·데이터 23개 | 9/20 메뉴에서 뺀 뒤 빵장 화면·API 어디서도 쓰지 않는다 |
| `web/public` | 날씨 아이콘 · 한지 질감 · 안 쓰는 이미지 · Next 기본 아이콘 | 위 절기 화면 전용이거나 아무 데서도 쓰지 않는다 |
| `docs/기획` | PRD v2.2·v2.3, 통합기획안·기획서 v8.1, 멘토 전달안, 계좌 데이터 방안, 인스타그램 출품, 기획 배경 기록 | 절기 콘테스트·호가창·내 종목 시절 설계라 지금 구조와 다르다 |
| `docs/페이지` | 절기 베이커리 캘린더 · 빵시장 한 장 요약 | 절기 콘테스트 시절 자료 |
| `deck` | V9 이전 HTML·PDF 발표덱과 그 이미지, V9 백업 PPTX | 최신은 `deck/MAKJI_최종발표덱_V10.html` |

되살릴 때는 `git mv old/<경로> <경로>`로 되돌리면 된다. 코드는 import 경로(`@/…`)가 그대로라 제자리에 두면 다시 동작한다.
